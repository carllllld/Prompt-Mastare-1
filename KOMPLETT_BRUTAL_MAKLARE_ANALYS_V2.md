## 🔴 KRITISKT PROBLEM #16: FORMULÄRET ÄR FÖR LÅNGT

### Vad jag ser:
Jag scrollar... och scrollar... och scrollar...

**Antal sektioner:** 15+  
**Antal fält:** 40+  
**Tid att fylla i:** 20-30 minuter

### Vad jag tänker:
**"Jag har inte tid med detta! Jag behöver texten NU!"**

### Varför detta är ett problem:
1. **Jag vet inte vad som är OBLIGATORISKT** - Allt ser lika viktigt ut
2. **Jag vet inte var jag ska börja** - Ingen tydlig prioritering
3. **Jag vet inte när jag är "klar nog"** - Kan jag skicka nu eller måste jag fylla i mer?

### Vad jag EGENTLIGEN behöver:
```
STEG 1: SNABBSTART (2 minuter)
┌────────────────────────────────────────┐
│ 🚀 SNABBSTART - Generera text på 2 min │
│                                        │
│ Adress: [Storgatan 12, Linköping]     │
│ Boarea: [76] kvm                       │
│ Rum: [3] Sovrum: [2] Badrum: [1]      │
│ Pris: [2500000] kr                     │
│ Avgift: [3500] kr/mån                  │
│                                        │
│ [Generera grundtext →]                 │
│                                        │
│ Vill du förbättra texten?              │
│ [Nej, jag är nöjd] [Ja, lägg till mer]│
└────────────────────────────────────────┘

STEG 2: FÖRBÄTTRA (valfritt, +5 min)
┌────────────────────────────────────────┐
│ 💎 FÖRBÄTTRA TEXTEN                    │
│                                        │
│ Lägg till dessa för bättre text:      │
│ ☐ Kök & badrum (viktigt!)             │
│ ☐ Läge & kommunikationer (viktigt!)   │
│ ☐ Försäljningsargument (viktigt!)     │
│ ☐ Planlösning                          │
│ ☐ Material & teknik                    │
│                                        │
│ [Generera förbättrad text →]           │
└────────────────────────────────────────┘
```

### Lösning:
**PROGRESSIV DISCLOSURE** - Visa bara det viktigaste först!

1. **Snabbstart-läge** (2 min):
   - Adress, boarea, rum, pris, avgift
   - "Generera grundtext" → Får en OK text direkt
   - "Vill du förbättra?" → Kan välja att fortsätta

2. **Förbättra-läge** (5 min):
   - Kök & badrum
   - Läge & kommunikationer
   - Försäljningsargument
   - "Generera förbättrad text" → Får bättre text

3. **Expert-läge** (15 min):
   - Alla fält synliga
   - För de som vill ha maximal kontroll
